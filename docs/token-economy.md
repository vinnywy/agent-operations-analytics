# Token economy

Context is assembled from a short protocol, structured profile, current task, selected skill and bounded evidence. The system uses deterministic code for hashes, schemas, state transitions and exact lookup. It does not ask a model to perform those operations.

Shared retrieval is two-stage: return up to five attributable summaries, then fetch a full record only when needed and authorized. The laboratory records returned bytes; provider token usage remains null unless the provider reports it. Timeouts bound waiting, not all provider billing.

Defaults are deliberately conservative: five summaries, 600 characters each and a 12 KiB response budget. The benchmark must show relevance before a limit changes. These are defaults to evaluate, not claims of optimal cost.
