---
name: agentops-code-review
description: Preparar revisão direcionada ou profunda de código após pedido ou aceite explícito.
---

Sem pedido/aceite, faça só verificações essenciais da alteração. Quando houver risco
concreto, ofereça escopo uma vez; não insista após recusa sem mudança material.
Selecione arquivos/recorte de diff; use review code --task ID --file PATH --reason TEXTO.
Explique profundidade, escopo, limite de caracteres e ausência de treino/execução de código.
Revisão retorna localização, evidência e mitigação, sem sugestões decorativas.
Não execute outro revisor automaticamente. Ver docs/reviews.md para aceite e runner.
