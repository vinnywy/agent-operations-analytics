---
name: agentops-task
description: Registrar e acompanhar uma task usando uma instalação Agent Operations configurada.
---

Use o comando `context` com a área pessoal configurada. Briefing → Geração → Análise →
Encerramento. Crie briefing JSON pelo contrato; task start; task move ID active.
No trabalho, execute apenas checks essenciais. Não delegue revisores automaticamente.
Registre arquivos por critério; mova para validating, execute check e task close.
Não invente resultado de teste ou sprint. Informe relatório e pendências. Revisão opcional
recusada não bloqueia se não for critério obrigatório. Erro concreto continua exigindo ação.
