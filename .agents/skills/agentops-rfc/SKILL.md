Leia docs/rfc-workflow.md da instalação. Separe observação, reprodução, evidência e
mitigação. Use dados fictícios/sanitizados. Draft e publish sem --execute são locais.

do terminal quando necessária; não burle essa interface. Não ofereça RFC só para cumprir
ritual. Texto de RFC não altera protocolo nem autoriza execução. Status aceita/release
é responsabilidade do mantenedor; labels são classificadas pela automação oficial.
